Privacy Policy

Local Time for Discord · Effective October 9, 2026

Local Time for Discord is a Discord Activity that lets users display the current time for a timezone they select.

Information we use

The Activity may access basic Discord account information required to authenticate the user and update the user's Discord activity status. The Activity also uses the timezone and clock-format preferences selected by the user.

Information we do not collect

Local Time for Discord does not collect Discord message content, server messages, contacts, precise location, payment information, or other sensitive personal information.

Storage

Timezone and clock-format preferences are intended to be stored locally in the user's browser or device. We do not sell personal information.

Third parties

Discord processes information associated with use of the Activity according to Discord's own policies and terms.

Changes

If the Activity's data practices change, this policy will be updated before those changes are introduced.

Contact

Questions about this policy or data deletion requests can be submitted through the project's GitHub Issues page.
